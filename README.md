# LottiePlayer

Unity project with **Mynell Lottie**, a Lottie player for Unity written in C# with Burst.

The package is in [`Assets/Mynell/Lottie`](Assets/Mynell/Lottie). Its [README](Assets/Mynell/Lottie/README.md) has the
setup, the API and a [comparison with other Lottie players for Unity](Assets/Mynell/Lottie/README.md#comparison-with-other-lottie-players-for-unity).

To try it, open the project in Unity 6000.3 and play `Assets/Mynell/Lottie/Samples/LottieSamples.unity`.
